# Privacy Pages Mirror — نسخ احتياطية لصفحات الخصوصية

نسخ احتياطية مطابقة للأصل من صفحات سياسات الخصوصية الأربع المنشورة على Vercel،
مُجهَّزة للنشر على GitHub Pages عند الحاجة (مثلًا إذا توقّف فريق Vercel المجاني
عند بلوغه حدّ نقل البيانات)، بحيث تُستبدل روابط المتاجر بالروابط الاحتياطية
أدناه دون تغيير في محتوى الصفحات.

أُعدّت هذه النسخ بتاريخ 2026-10-19 من مصادر المشاريع المحلية، وتحقّق من
تطابقها بايتًا ببايت مع المصادر، ومن احتواء كلٍّ منها على سطر المطوّر
«المطوّر: سفيان الدوري (Sufyan Aldoori)» المُضاف بتاريخ 2026-10-18.

## ملاحظات

- هذه النسخ لقطة بتاريخ الإعداد أعلاه؛ أي تعديل مستقبلي على صفحة حية يجب أن
  يُعاد نسخه هنا قبل الاعتماد على المرآة.
- لم يُرفع أي ملف بعد؛ النشر على GitHub Pages خطوة لاحقة منفصلة عند الحاجة.
